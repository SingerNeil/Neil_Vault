# 猫类宠物视频生成标准 Prompt

适用于 Seedance、即梦等图生视频工具。六段视频使用同一张绿幕中性姿态母图作为身份参考；平台支持首尾帧时，同一张母图同时作为首帧和尾帧。

时长只在生成平台参数中选择，不写入 Prompt 的动作过程：

| 文件名 | 平台时长 |
|---|---:|
| `01-idle-breathe` | 5 秒 |
| `02-idle-yawn` | 5 秒 |
| `03-idle-lick-paw` | 5 秒 |
| `04-idle-stretch` | 6 秒 |
| `05-interact-belly` | 6 秒 |
| `06-interact-hiss` | 5 秒 |

## 1. 自然呼吸｜`01-idle-breathe`

```text
以首尾帧中的同一只猫咪为唯一主体。猫咪保持参考图中的正面中性姿态，像真实猫咪安静休息一样自然呼吸，胸口和腹部轻柔起伏，偶尔自然眨眼；耳尖、胡须、胸口毛发和尾巴尖带有非常轻微的生命感。整体动作克制、松弛、连续、不机械，身体不走动，最后自然回到与首尾帧完全相同的中性姿态，适合顺畅循环。

镜头和构图保持固定，纯绿色背景稳定均匀。猫咪全身始终完整可见，耳尖、胡须、毛发外缘、四肢、爪尖和尾巴都不能被裁切。保持参考图中的脸型、眼睛颜色、毛色、花纹、体型和肢体结构，不增加其他人物、动物、物体、文字或水印。
```

## 2. 打哈欠｜`02-idle-yawn`

```text
以首尾帧中的同一只猫咪为唯一主体。猫咪保持参考图中的中性姿态，自然显露出困意，眼睛缓慢眯起，头部略微抬起，嘴巴自然张开，完成一次符合真实猫咪口腔和下颌结构的哈欠，舌头可以短暂露出。哈欠结束后自然闭合嘴巴，胡须和耳朵恢复放松状态，并恢复首尾帧中的原始姿态。动作要有真实动物自然的预备、展开和收势，只完成一次哈欠，不要像机械表演。

镜头和构图保持固定，纯绿色背景稳定均匀。猫咪全身始终完整可见，抬头和张嘴时也不能裁切耳朵、下颌、胡须、四肢、爪尖或尾巴。保持参考图中的身份、外貌、体型、眼睛颜色和毛色花纹，不增加其他人物、动物、物体、文字或水印。
```

## 3. 舔爪子｜`03-idle-lick-paw`

```text
以首尾帧中的同一只猫咪为唯一主体。猫咪安静保持参考图中的中性姿态，自然抬起一只前爪靠近嘴边，稍微低下头，用舌头轻轻舔舐爪面和爪毛，呈现真实猫咪日常理毛的细腻动作。随后自然放下前爪，重新抬头，并恢复首尾帧中的原始姿态。身体重心、肩部、胡须、耳朵和毛发应随着动作自然变化，动作不要刻意、僵硬或机械，不要反复更换前爪，也不要把动作扩展成擦脸或全身理毛。

镜头和构图保持固定，纯绿色背景稳定均匀。猫咪全身始终完整可见，抬起的前爪、留在地面的爪子、胡须和尾巴都不能被裁切或消失。保持参考图中的身份、外貌、体型、眼睛颜色、毛色花纹和肢体数量，不增加其他人物、动物、物体、文字或水印。
```

## 4. 伸懒腰｜`04-idle-stretch`

```text
以首尾帧中的同一只猫咪为唯一主体。猫咪从参考图中的中性姿态自然起身，两只前爪向前伸出并贴近地面，前胸缓慢下沉，背部形成柔和弧线，臀部抬起，尾巴随着身体舒展自然延伸，完成一次典型而真实的猫咪伸懒腰。伸展结束后自然收回四肢，重新回到原来的位置，并恢复首尾帧中的原始姿态。动作柔韧、舒展，具有真实猫科动物的骨骼结构、重心变化和身体重量感，不要跳跃、奔跑或横向行走。

镜头和构图保持固定，纯绿色背景稳定均匀。画面要为伸展动作保留充足空间，向前伸出的爪尖、耳朵、胡须、臀部、毛发和整条尾巴始终完整留在画面内。保持参考图中的身份、脸型、眼睛颜色、毛色花纹、体型和身体比例，不增加其他人物、动物、物体、文字或水印。
```

## 5. 躺下露肚皮｜`05-interact-belly`

```text
以首尾帧中的同一只猫咪为唯一主体。猫咪从参考图中的中性姿态自然向一侧卧倒，顺势翻身露出腹部，背部轻柔贴地，四只爪子放松地微微弯曲，尾巴随着身体自然移动，表现出信任、放松和撒娇的状态。随后自然翻回侧卧，在原地重新起身，并恢复首尾帧中的原始姿态。动作柔软、连贯，符合真实猫咪的骨骼结构、重心变化和身体重量感；不要瞬间倒下，不要在地面滑动，不要持续翻滚，也不要以躺卧姿态结束。

镜头和构图保持固定，纯绿色背景稳定均匀。画面要为横向卧倒和翻身保留充足空间，耳朵、胡须、背部、腹部、四肢、所有爪尖和整条尾巴始终完整可见。保持参考图中的身份、外貌、体型、眼睛颜色、毛色花纹和肢体结构，不增加其他人物、动物、物体、文字或水印。
```

## 6. 哈气挥爪｜`06-interact-hiss`

```text
以首尾帧中的同一只猫咪为唯一主体。猫咪保持在原地，做出一次短暂、克制并符合真实猫咪行为的警告动作：耳朵稍微向后，身体自然绷紧，嘴巴张开并哈气，同时抬起一只前爪向前方挥动。挥爪只在身体前方的小范围内自然完成，不向镜头扑出，不前进、不跳跃，也不真正攻击。动作结束后自然闭合嘴巴、放下前爪，耳朵和身体重新放松，并恢复首尾帧中的原始姿态。整个过程连贯自然，不要连续拍打、夸张咆哮或变成机械重复动作。

镜头和构图保持固定，纯绿色背景稳定均匀。猫咪全身始终完整可见，哈气和挥爪时的耳尖、嘴部、胡须、抬起的前爪、其余四肢、爪尖和整条尾巴都不能被裁切。保持参考图中的身份、脸型、眼睛颜色、身体比例、毛色花纹和肢体结构，不增加其他人物、动物、物体、文字或水印。
```

## 生成后优先检查

“伸懒腰”和“躺下露肚皮”最容易失败，“哈气挥爪”最容易出现脸部或前爪变形。优先检查：

1. 动作结束后是否完整回到母图姿态。
2. 四肢、爪子、脸部、胡须和尾巴是否变形或消失。
3. 动作幅度变大时，身体是否被画面裁切。
