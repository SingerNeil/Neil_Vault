# 狗类宠物视频生成标准 Prompt

适用于 Seedance、即梦等图生视频工具。六段视频使用同一张绿幕中性姿态母图作为身份参考；平台支持首尾帧时，同一张母图同时作为首帧和尾帧。

时长只在生成平台参数中选择，不写入 Prompt 的动作过程：

| 文件名 | 平台时长 |
|---|---:|
| `01-idle-breathe` | 5 秒 |
| `02-idle-yawn` | 5 秒 |
| `03-idle-lick-paw` | 5 秒 |
| `04-idle-stretch` | 6 秒 |
| `05-interact-belly` | 6 秒 |
| `06-interact-shake` | 5 秒 |

## 1. 自然呼吸｜`01-idle-breathe`

```text
以首尾帧中的同一只狗狗为唯一主体。狗狗保持参考图中的正面中性姿态，像真实狗狗安静休息一样自然呼吸，胸口和腹部轻柔起伏，偶尔自然眨眼，耳朵、尾巴和毛发带有非常轻微的生命感。整体动作松弛、连续、不机械，身体不走动，最后自然回到与首尾帧完全相同的中性姿态，适合顺畅循环。

镜头和构图保持固定，纯绿色背景稳定均匀。狗狗全身始终完整可见，耳朵、四肢、爪尖、毛发外缘和尾巴都不能被裁切。保持参考图中的脸型、毛色、花纹、体型和肢体结构，不增加其他人物、动物、物体、文字或水印。
```

## 2. 打哈欠｜`02-idle-yawn`

```text
以首尾帧中的同一只狗狗为唯一主体。狗狗保持参考图中的中性姿态，自然显露出困意，眼睛微微眯起，头部轻轻抬起，嘴巴自然张开，完成一次真实可爱的哈欠，舌头可以短暂露出。哈欠结束后自然合上嘴巴、放松表情，并恢复首尾帧中的原始姿态。动作要有真实动物自然的预备、展开和收势，只完成一次哈欠，不要像机械表演。

镜头和构图保持固定，纯绿色背景稳定均匀。狗狗全身始终完整可见，抬头和张嘴时也不能裁切耳朵、下颌、四肢、爪尖或尾巴。保持参考图中的身份、外貌、体型和毛色，不增加其他人物、动物、物体、文字或水印。
```

## 3. 舔爪子｜`03-idle-lick-paw`

```text
以首尾帧中的同一只狗狗为唯一主体。狗狗安静保持参考图中的中性姿态，自然抬起一只前爪靠近嘴边，稍微低下头，轻轻舔舐这只前爪和爪毛，像真实狗狗日常整理毛发一样自然。随后自然放下前爪，重新抬头，并恢复首尾帧中的原始姿态。身体重心、耳朵和毛发应随着动作自然变化，动作不要刻意、僵硬或机械，不要反复更换前爪。

镜头和构图保持固定，纯绿色背景稳定均匀。狗狗全身始终完整可见，抬起的前爪、留在地面的爪子和尾巴都不能被裁切或消失。保持参考图中的身份、外貌、体型、毛色和肢体数量，不增加其他人物、动物、物体、文字或水印。
```

## 4. 伸懒腰｜`04-idle-stretch`

```text
以首尾帧中的同一只狗狗为唯一主体。狗狗从参考图中的中性姿态自然起身，将两只前爪向前伸展，前胸向下靠近地面，臀部轻轻抬起，完成一次真实狗狗常见的伸懒腰动作。耳朵、尾巴和毛发随着身体舒展自然移动。伸展结束后自然收回四肢，重新回到原来的位置，并恢复首尾帧中的原始姿态。动作舒展、柔和、有真实的身体重量感，不要跳跃、奔跑或横向行走。

镜头和构图保持固定，纯绿色背景稳定均匀。画面要为伸展动作保留充足空间，向前伸出的爪尖、耳朵、臀部、毛发和整条尾巴始终完整留在画面内。保持参考图中的身份、脸型、毛色、体型和身体比例，不增加其他人物、动物、物体、文字或水印。
```

## 5. 躺下露肚皮｜`05-interact-belly`

```text
以首尾帧中的同一只狗狗为唯一主体。狗狗从参考图中的中性姿态自然向一侧躺下，顺势翻身露出肚皮，四只爪子放松地微微蜷起，表现出信任、撒娇和舒服的状态。随后自然翻回侧卧，在原地重新起身并恢复首尾帧中的原始姿态。整个动作连贯、可爱，符合真实狗狗的骨骼结构、重心变化和身体重量感，不要瞬间倒下，不要在地面滑动，也不要以躺卧姿态结束。

镜头和构图保持固定，纯绿色背景稳定均匀。画面要为横向躺开和翻身保留充足空间，头部、背部、肚皮、四肢、所有爪尖和整条尾巴始终完整可见。保持参考图中的身份、外貌、体型、毛色和肢体结构，不增加其他人物、动物、物体、文字或水印。
```

## 6. 甩甩身子｜`06-interact-shake`

```text
以首尾帧中的同一只狗狗为唯一主体。狗狗稳住四只脚，像刚整理完毛发一样，从头部开始自然带动颈部、躯干和尾巴，完成一次连贯真实的全身甩动。耳朵、皮肤、毛发和尾巴随着甩动产生柔软、轻快并符合惯性的摆动，四只脚保持稳定，不跳跃也不走动。甩动结束后自然稳定下来，整理好身体姿态，并恢复首尾帧中的原始姿态。动作只完成一次，不要变成重复甩动、快速抽搐或夸张旋转。

镜头和构图保持固定，纯绿色背景稳定均匀，不出现背景晃动或绿色污染毛发。甩动时展开的耳朵、毛发、四肢、爪尖和尾巴始终完整留在画面内。保持参考图中的脸型、身体比例、毛色和肢体结构，不增加其他人物、动物、物体、文字或水印。
```

## 生成后优先检查

“伸懒腰”和“躺下露肚皮”最容易失败，优先检查：

1. 动作结束后是否完整回到母图姿态。
2. 四肢、爪子、脸部和尾巴是否变形或消失。
3. 动作幅度变大时，身体是否被画面裁切。
